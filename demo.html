Live Display

Two ways the designer can place the urgency content. Both pull from the same data and update on the same schedule.

Approach A — card slots

Best for the main "pick your start date" block. Slot 2 hides automatically when there's only one date to show; gets a yellow background in the high-price state.

Approach B — named variables (use anywhere)

Drop these into any sentence on any page in the funnel. The script fills them in and hides them when the data isn't applicable.

Markup the designer writes

Set the dates once per page (a hidden div is fine):

<div data-fu-dates="2026-06-08,2026-06-15,2026-06-22,2026-06-29" hidden></div>

Card-style markup (Approach A):

<div data-fu-slot="1">
  <span data-fu-date>Monday, June 8</span>
  <span data-fu-spots>6 spots left</span>
</div>
<div data-fu-slot="2">
  <span data-fu-date>Monday, June 15</span>
  <span data-fu-spots>9 spots left</span>
</div>

Inline named variables (Approach B):

Sign up for <span data-fu-var="startdate1"></span>
— <span data-fu-var="spotsleft1"></span>!

<span data-fu-show-if-slot="2">
  Or grab a spot for <span data-fu-var="startdate2"></span>
  (<span data-fu-var="spotsleft2"></span>).
</span>
