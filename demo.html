Markup the designer adds

Set the dates once per landing page (a hidden div is fine):

<div data-fu-dates="2026-06-08,2026-06-15,2026-06-22,2026-06-29" hidden></div>

Mark the two slots in the existing design. The script writes text into whatever element carries data-fu-date and data-fu-spots:

<div data-fu-slot="1">
  <span data-fu-date>Monday, June 8</span>
  <span data-fu-spots>6 spots left</span>
</div>
<div data-fu-slot="2">
  <span data-fu-date>Monday, June 15</span>
  <span data-fu-spots>9 spots left</span>
</div>
